# Chaos Manager

Локальный персональный планировщик без регистрации и backend. Данные хранятся в `localStorage` браузера.

## Запуск

Откройте `index.html` в современном браузере. Для публикации достаточно импортировать папку проекта в Vercel как статический сайт.

Быстрое добавление открывается сочетанием `Ctrl/Cmd + K` или `Ctrl/Cmd + N`.
